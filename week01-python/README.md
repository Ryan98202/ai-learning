## 卡住了怎么办

**先读文件里的注释。** 每个 TODO 上面都写了"这行要做什么"，注释不是装饰，是题目的一部分。

**卡超过 10 分钟，再看答案。** 答案在 `solutions/` 文件夹里，同名文件。规矩是：**看完答案要把答案文件关掉，自己重新敲一遍**。抄一遍不算学会，但抄完之后删掉重写一遍，算。

**报错不要怕。** 你现在会遇到的错误基本只有三种：

| 报错 | 意思 | 怎么改 |
|---|---|---|
| `NameError: name 'xxx' is not defined` | 用了一个没定义过的名字 | 检查拼写，或者这个变量你还没赋值 |
| `IndentationError` | **缩进错了** | Python 靠缩进判断层次，`if` / `while` / `def` 下面的代码必须往里缩 4 个空格 |
| `ValueError: invalid literal for int()` | 想把不是数字的文字转成数字 | `input()` 拿到的永远是文字，`int()` 只能转纯数字的文字 |

**缩进这件事要单独说一句**：其他语言用大括号 `{}` 表示"这几行是一组"，Python 用**空格**。所以行首的空格不是排版好看，是语法。VS Code 会帮你自动缩进——按回车时它自己往里缩，你直接打字就行，不用手动敲空格。

## 术语表（先扫一眼，遇到再看）

| 词 | 一句话解释 |
|---|---|
| 变量 | 给一个值起的名字。`name = "Ryan"` 之后，`name` 就代表 `"Ryan"` |
| 字符串 | 一段文字，用引号包起来。`"你好"`、`'abc'` 都是 |
| f-string | 往文字里塞变量的写法。`f"你好 {name}"` |
| 函数 | 一段打包好的代码，起个名字，以后叫名字就能重复用。`def` 开头 |
| 参数 | 传给函数的输入 |
| 返回值 | 函数算完之后交出来的结果，用 `return` 交 |
| 条件 | `if`：如果……就…… |
| 循环 | `while` / `for`：反复做同一件事，直到条件不成立 |
| 列表 | 一串有顺序的值，用方括号。`[1, 2, 3]` |
| 字典 | 一堆"名字 → 值"的配对，用花括号。`{"苹果": 3}` |
| 缩进 | 行首的空格。Python 用它表示层次，**是语法不是排版** |
| 报错（Traceback） | 程序崩了之后的说明。**从最后一行往上读**，最后一行是原因 |
